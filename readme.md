Download from store: https://microsoftedge.microsoft.com/addons/detail/colorful-bionic-reading/camgbnhlhdempnekobebpmdhechifjni



**Enhance your reading experience with colorful bionic reading technology!**

Colorful Bionic Reading transforms any webpage by highlighting the first part of each word in vibrant colors, helping you read faster with better comprehension and less eye strain.

🌈 **Three Color Modes:**
- Rainbow Mode - Cycles through 6 vibrant colors automatically
- Single Color - Choose one consistent color for focus
- Custom Palette - Create your own collection of up to 8 colors

⚙️ **Complete Customization:**
- Font Size Control (80% - 150%)
- Bold Weight Selection (6 levels from normal to ultra-bold)
- Color Intensity Adjustment (30% - 100%)
- Word Highlighting Ratio (20% - 80%)

✨ **Smart Features:**
- Instant real-time preview
- One-click enable/disable toggle
- Performance optimized for large pages
- Works on all websites
- Preserves original page layout

🎯 **Perfect For:**
- Students studying online materials
- Professionals reading documents and emails
- Anyone wanting to reduce reading fatigue
- Users with reading difficulties or visual preferences

🔒 **Privacy Focused:**
- All settings stored locally
- No data collection
- Works completely offline
- Lightweight and secure

## Installation
1. Download or clone this repository
2. Open Edge browser
3. Go to `edge://extensions/`
4. Enable Developer mode
5. Click "Load unpacked" and select the extension folder
